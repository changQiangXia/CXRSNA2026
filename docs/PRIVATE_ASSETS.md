from other authors; those are listed in the individual `kernel-metadata.json`

are the private account-owned assets referenced by the archived final

## Confirmation status

These links were checked against the `intoxicatinglips` Kaggle dataset listing.
The notebooks and `kernel-metadata.json` files still contain the raw attach
handles because they are provenance records; this document supplies the
human-readable links.

The repository does **not** redistribute the bytes of these datasets, trained
weights, or private labels. Access depends on the owner’s Kaggle permissions
and the original artifact licenses.
